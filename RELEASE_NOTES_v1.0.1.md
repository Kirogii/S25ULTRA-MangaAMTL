# v1.0.1

This release improves live screen translation stability on Galaxy S25 Ultra:

- More reliable scrolling, region tracking, clipping, and stale-result handling.
- Safer live capture start/stop behavior and bounded in-memory history.
- Google Lens OCR plus Samsung Translate measured at about 1.07 seconds in the warm benchmark.
- Samsung Translate requires the Samsung Interpreter/Translate app and installed language packs.
- The APK contains no AI model weights; optional model packs remain downloadable separately.
- Includes the Android APK and browser extension package built by GitHub Actions.
